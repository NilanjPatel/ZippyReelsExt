# Quick Reference Guide

## 🚀 Getting Started in 3 Minutes

### 1. Install (2 minutes)
```
1. Open generate-icons.html → Download all 4 icons → Save to icons/ folder
2. Open chrome://extensions/ → Enable "Developer mode"
3. Click "Load unpacked" → Select social-media-downloader folder
4. Done!
```

### 2. First Use (1 minute)
```
1. Click extension icon
2. Read ethical agreement
3. Check "I agree" box
4. Click "Continue"
```

### 3. Download Video (30 seconds)
```
Method 1: Click download button on video
Method 2: Press Ctrl+Shift+D (Cmd+Shift+D on Mac)
Method 3: Right-click → "Download with Social Media Downloader"
```
